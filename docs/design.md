# PaperFraud Detect — 设计文档

## 一句话定位

**不是 ChatGPT 套壳。** 这是一个多层交叉校验引擎，用规则引擎 + 统计检验 + LLM 定性分析的三层架构，检测生命科学论文中的造假信号。

---

## 系统边界

### 能做什么

| 层级 | 能力 | 示例 |
|------|------|------|
| **文本模式** | 统计量反算、p-hacking 检测、黑名单话术 | 报告 p=0.032 但 t 值和 df 反算不出这个 p 值 |
| **数值校验** | GRIM 检验、尾数偏好、小数位一致性、Benford | 三个组的均值都是整数，但 SEM 显示小数——数据不可能来自真实测量 |
| **统计方法** | 样本量功效分析、p 值分布、效应量临界值 | n=3 声称 p<0.001：需要 d≥3.5，生物实验中几乎不可能 |
| **图像取证** | LUT 伪彩、ELA 误差分析、克隆区域检测 | 生成辅助可视化图，不做自动判定 |
| **LLM 审查** | 跨信号关联、假阳性过滤、PubPeer 草稿 | "尾数偏好 + p 值集中在 0.04 + 小数位不一致 → 统计造假模式，非孤立噪声" |

### 不能做什么（诚实边界）

- **图像自动判定** — 评估后决定保留人工审查节点。ELA/LUT/Clone 只生成辅助图，不产生 red/orange 信号。原因：medical-grade 准确率要求下，80% 的 AI 图像检测准确率不可接受。
- **原始数据交叉校验** — 需要论文的原始 Excel/CSV 数据文件。这是 Phase 2 目标，通过 `--data-file` 传入。
- **跨论文系统性造假检测** — 目前单篇分析。同课题组/同实验室跨论文比对需要建立作者-机构知识图谱。
- **非 PDF 格式** — 仅处理 PDF。Word/LaTeX 源文件需要额外适配。
- **非生命科学领域** — 规则和阈值针对生物医学实验设计。心理学（问卷量表）和物理学需要不同的检测规则。

## 架构：三层交叉校验引擎

```
PDF → PyMuPDF 提取文本/图片
  │
  ├─ ParsedPaper (不可变中间表示，ThreadPoolExecutor 并行安全)
  │
  ├─ 第一层：规则引擎 (14 条硬编码学科规则)
  │   ├─ 数值: statcheck, GRIM, 尾数偏好, 小数位一致性, 组间算术
  │   ├─ 文本: 黑名单词扫描, p 值伪装话术
  │   ├─ 统计: 样本量功效, p 值分布, 效应量分析
  │   ├─ 图像: LUT, ELA, 克隆检测 (仅生成辅助图)
  │   └─ 生信: Western blot 质量控制
  │
  ├─ 第二层：统计分析 (scipy 精确检验)
  │   ├─ t 分布反算 p 值 (非近似)
  │   ├─ 效应量临界值: d_min = t_crit(α, df) × sqrt(2/n)
  │   └─ GRIM: 粒度一致的均值不可能来自整数测量
  │
  ├─ 第三层：LLM 定性审查 (DeepSeek/Anthropic/OpenAI)
  │   ├─ 逐信号真锤/假阳性判定
  │   ├─ 跨信号关联分析 (多项信号指向同一底层问题 → 可信度提升)
  │   └─ PubPeer 审稿草稿 (引用具体证据)
  │
  └─ 风险评分 → HTML 报告 + 终端输出 + Streamlit Web UI
```

**关键设计决策：三层为什么必须分开**

| | 规则引擎 | 统计分析 | LLM 审查 |
|---|---|---|---|
| 确定性 | 100% | 100% | 不可控 |
| 可解释性 | 完全可追溯 | 数学公式 | 需二次确认 |
| 假阳性率 | 可调阈值 | 已知 Type I error | 取决于 prompt |
| 成本 | 零 | 零 | 按 token 计费 |

规则引擎 + 统计分析构成"不需要 LLM 的安全网"——这两层发现的问题有数学确定性支撑。LLM 作为第三层提供定性判断和跨信号关联，但不替代前两层。**如果只用 LLM 一把梭，面试官一眼就知道你是外行。**

## 核心规则设计（证明你懂科学）

### 规则 1: 样本量 < 3 → 统计检验不成立

不是"功效低"，是"检验根本不成立"。n=2 时每组自由度 = 1，方差估计 = 单点方差，t 分布退化为 Cauchy 分布（无定义方差）。

```python
# 按实验类型分级，而非全局 min(n)
n_claims_lt3 = sum(1 for c in sus_claims if c["n"] < 3)
if methods_min < 3:              # Methods 自身声明 n<2
    level = "red"
elif n_claims_lt3 >= 2:          # 多处 n<3 + 显著声称
    level = "red"
elif n_claims_lt3 == 1:          # 单处可疑
    level = "orange"
```

**面试话术：** "纯 CS 的人会算出 p 值就收工。做实验的人知道，n=2 的方差估计本身就是无意义的——这不是统计功效问题，是数学前提不成立。我们的检测不会因为 Methods 某处出现一个孤立的 n=2 就标红整篇论文，而是逐条声明独立分析。"

### 规则 2: p 值全部集中在 0.04-0.05 → p-hacking

基于 Masicampo & Lalande (2012) 的 p-curve 方法。健康 p 值分布应均匀或右偏。检测模式：
- `p ≈ 0.01` 出现 17 次——多个 p 值精确相同极不寻常
- `p ≈ 0.04` 出现 11 次——经典 p-hacking 标志
- `p > 0.05` 占比 < 15%——文件抽屉效应

### 规则 3: Western blot 无 loading control → 缺失上样量对照

这是做实验的人的隐性知识。Western blot 条带宽度与蛋白上样量成正比，没有 loading control（β-actin/GAPDH/tubulin）就无法判断差异条带是真实的表达差异还是上样量误差。检测逻辑：扫描 Methods 段落，检查是否提及 loading control 或其替代方案（总蛋白染色、Ponceau S）。

### 规则 4: 负向过滤防止引用污染

150-char 上下文窗口内命中 "et al" / "previously" / "reported by" / "database" / "GEO" → 跳过。防止把他人的 n=3 误标为本论文的方法论问题。

## 工程实践

### 线程安全
`ParsedPaper` 解析后只读。18 个检查通过 `ThreadPoolExecutor(max_workers=8)` 并行执行，Python 字符串不可变性保证零锁。单个检查崩溃不级联，生成 `level="error"` 的 CheckResult 继续。

### 图像管线
图片写入 `tempfile.mkdtemp()` 而非 PDF 同级目录。`atexit` + 主动 `shutil.rmtree` 双重保障清理。Web UI 通过 base64 编码内嵌图片，无需静态文件服务器。

### 依赖策略
能不引入就不引入。`pyproject.toml` 11 个依赖，全部必需。`cv2.img_hash` 不可用 → 手写 8×8 averageHash（20 行，零额外依赖）。

## 与 Medge AI 的关系

Medge AI 做医学知识图谱 + 科研智能体。PaperFraud 本质上是**科学知识的自动化校验**——两者共享同一技术栈：

1. **知识图谱** — Medge 的医学术语本体可直接用于论文方法论参数的结构化抽取（试剂名称、细胞系、统计方法标准化）
2. **规则引擎** — PaperFraud 的学科常识规则（如 "Western blot 需要 loading control"）可以扩展为 Medge 科研智能体的方法论审查模块
3. **LLM 审查** — PaperFraud 的 prompt 工程和结构化输出方案可复用到 Medge 的文献自动化审查 pipeline
4. **差异化价值** — 纯 NLP 团队做论文检测只会调 NER API。PaperFraud 证明了：知道"该提取什么"比"怎么提取"重要得多。这种科学过程的结构化能力是 Medge 与纯 AI 公司的核心区分点。
