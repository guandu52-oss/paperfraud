# 外部论文造假检测 Workflow — 实操核查清单

## 设计理念

只凭已发表论文的公开信息（PDF + 补充材料 + 公开数据库）+ 免费/低成本工具，逐层筛查造假行为。不需要接触原始数据、实验室记录或内部系统。

**核查顺序：** 从最快、信号最强的维度开始。每一步能独立出红灯，不需要等全部跑完。

| 步骤 | 检测维度 | 耗时 | 信号强度 | 关键杀招（生科定制） |
|---|---|---|---|---|
| Step 1 | 逻辑与动机刺探 | 5-10 分钟 | 中 | Overclaim 边界比对、因果断言标注、抗体/试剂货号可追溯性 |
| Step 2 | 图像法医学 | 20-40 分钟 | 强 | LUT 伪彩映射、Forensically Clone Detection、跨图复用、显微镜比例尺/同视野荧光、流式门控百分比 |
| Step 3 | 数字三角对账 | 20-40 分钟 | 强 | N 数死磕、P 值反算、GRIM/尾数偏好/小数位一致性、本福特定律、组间算术关系检测、动物/剂量曲线形态 |
| Step 4 | 生信代码与公开数据逆向 | 30 分钟-数小时 | 中强 | 硬编码剔除、公开数据库复现、多重比较校正、RNA-seq Count/基因长度比值验证 |
| Step 5 | 文本与 AI 滥用排查 | 10-15 分钟 | 中 | 黑名单词扫描、GPTZero（参考）、P 值伪装话术检索、结果-讨论矛盾比对 |

---

## Step 1 · 逻辑与动机刺探

> 不碰数据，只读 Introduction 和 Discussion。造假文章数据可以天衣无缝，但故事动机往往是硬凑的。

### 1.1 生态/临床逻辑审视

**检测什么：** 研究的病原体、宿主、介质、机制在现实中能否合理关联？

**操作方法：**
1. 读 Abstract，提取核心假说：X 因子 → Y 机制 → Z 疾病
2. 逐环节检查：三者之间的关联在已知文献中是否有支撑？
3. 如果论文强行把毫无生态重叠的病毒和媒介联系在一起 → **为凑课题凭空捏造的伪需求**

**红灯条件：**
- 核心假说中至少一个环节缺乏任何已知文献支撑
- 作者未在 Introduction 中解释为何研究这个"冷门"关联
- 实验模型与声称的临床场景无合理桥接（如用细胞系结果直接推断人群流行病学）

### 1.2 Overclaim 识别

**检测什么：** 结论是否超出了实验材料能证明的真实范围？

**操作方法：**
1. 定位 Methods，记录实验使用的：物种、细胞系、样本来源、样本量
2. 读 Discussion 第一段和最后一段（这里通常是结论最"大胆"的地方）
3. 逐条比对：每个声称是否被 Methods 中实验材料的能力范围所覆盖？

**典型案例：**
- 在新西兰白兔和长角血蜱模型上观察到病毒传播 → Discussion 断言揭示了该病原体在自然界人群中的普遍传播规律
- 细胞系实验显示药物抑制某通路 → Discussion 声称该药物可用于临床治疗
- 相关性分析（R=0.4）→ Discussion 使用因果语言（"A 导致 B"）

**红灯条件：**
- 结论跨物种、跨实验体系过度推广，且未在 Limitations 中明确声明
- 相关性发现使用因果断言，且无实验证据支撑

### 1.3 因果断言标注检查

**检测什么：** 论文声称因果关系的句子，是否标注了对应的实验证据？

**操作方法：**
1. Ctrl+F 搜索：`activates`、`induces`、`mediates`、`regulates`、`drives`、`triggers`、`leads to`、`causes`
2. 每个命中的因果断言检查：后面是否跟了实验证据编号？如 `(Fig. 3C-D, Co-IP; Fig. 4A, WB)`
3. 无标注的因果断言 → 退回，应降级为相关性表述

### 1.4 试剂与抗体可追溯性（生科专属）

**检测什么：** 编造的实验中，作者常忘记标注试剂/抗体的货号和批次——这些东西是真实购买行为才会有的信息。

**操作方法：**
1. 定位 Methods 中"Reagents"、"Antibodies"、"Chemicals" 段落
2. 逐条检查：每种抗体是否标注了 **Catalog Number（货号）** 和 **RRID**？
3. 检查关键试剂盒（如 RNA 提取、WB 显色、ELISA 试剂盒）是否有货号和制造商
4. 交叉比对：论文声称使用的抗体/试剂盒在制造商官网上是否确实存在？

**判定：**
- 核心实验（Co-IP、WB 关键条带、免疫组化）使用的抗体无货号 → **实验不可复现，高度可疑**
- 抗体货号在制造商官网搜索不到 → 货号伪造
- 多种抗体连续缺失货号 → 实验可能根本未做

**红灯条件：**
- ≥ 3 种关键抗体/试剂盒无货号或 RRID
- 货号在官网上不存在
- Methods 试剂段仅出现通用名称（如"anti-p53 antibody"）而无任何商品化标识

## Step 2 · 图像法医学

> 最高效、最容易定死造假的突破口。不需要原始文件，有高清 PDF 截图即可。

### 2.1 暴力调雪花点（背景噪点分析）

**工具：** Photoshop / GIMP（免费）/ Fiji/ImageJ（免费）

**方法 A · 对比度拉伸：**
1. 从 PDF 中截取电泳胶图或 Western Blot 图片（分辨率不低于 300dpi）
2. 导入 Fiji/ImageJ：`Image → Adjust → Brightness/Contrast`，将对比度拉到最大
3. 或用 Photoshop：`图像 → 调整 → 色阶`，将输入色阶压缩到极窄范围
4. 观察背景噪点分布

**判定（方法 A）：**
- 真实胶图：背景噪点随机且连续分布，无明显断层
- 拼接图片：在拼接边缘处出现平滑的断层线，或拼接区域两侧的噪点纹理突然改变
- 同一条带的背景"过于干净"→ 可能被 Photoshop 修饰过

**方法 B · 伪彩映射 LUT（抓拼接的终极杀器）：**

痛点：暴力拉对比度对单色胶图（黑白灰）有时效果有限。造假老手会故意把背景抹得很匀，灰度断层肉眼难辨。

操作：
1. 将 WB/胶图截图导入 Fiji/ImageJ
2. 点击 `Image → Lookup Tables → Fire` 或 `Royal`
3. 这会将人眼难以区分的灰色阶映射成极度反差的伪彩色（如蓝→青→黄→红）
4. 观察条带周围区域的颜色过渡

判定：
- 真实胶图背景：颜色呈自然的像素级渐变过渡，无规则几何边界
- 拼接条带：条带周围出现如同"贴邮票"一样的、边缘极其锐利的长方形/矩形纯色框——这是因为复制粘贴区域在伪彩映射下，即使灰度接近，颜色跳变也会暴露边界
- 这是目前打假圈公认抓 WB 拼接的最强单招

**综合红灯条件：**
- 方法 A 或 B 任一发现明确的噪点断层线/矩形纯色框
- 同一张图内不同区域背景纹理/颜色不一致

**假阳性防护 · PDF 压缩伪影陷阱：**

许多期刊在生成最终版 PDF 时会对图片进行重度 JPEG 压缩。在 Fiji/ImageJ 中拉满对比度或使用 LUT 伪彩时，PDF 自身的 8×8 像素压缩块（Block Artifacts）有时看起来会非常像长方形的拼接痕迹。

- **对策：** 遇到疑点时，必须尽量下载高分辨率的原始 Supplementary 图片（通常期刊网站提供独立下载的 TIFF/PNG 原图）进行复核
- **不能仅凭正文 PDF 截图就下"拼接"的死论**——PDF 截图发现的疑点只能作为标记，复核后的 Supplementary 原图中确认存在同样异常才能列为实锤
- **区分技巧：** JPEG 压缩块的边界通常均匀分布在整个图片，而拼接边界只在特定区域出现。如果"矩形框"遍布整张图 → 压缩伪影；仅出现在某一条带周围 → 拼接嫌疑

### 2.2 跨图/跨论文复用检索

**工具：** ImageTwin（付费但可试用）/ 人工肉眼比对

**操作方法：**
1. 将同一论文内所有 WB/胶图 Panel 截图放在一起，并排比对
2. 重点检查：内参条带（GAPDH、β-actin）是否在不同 Panel 间重复出现
3. 将图片水平翻转、旋转后再次比对（造假者常用手法）
4. 在 PubPeer 上搜索该论文，看是否已有其他人标记了图像问题
5. 如有条件，用 ImageTwin 上传 PDF，自动跨图比对

**判定：**
- 内参条带形状、间距、相对强度在不同 Panel 中完全一致 → 复用
- 条带经翻转/旋转后与另一 Panel 完全吻合 → 实锤复用

**红灯条件：**
- 同一论文内发现 ≥ 1 处条带复用
- 同一作者多篇论文间发现相同图片

### 2.3 AI 生成痕迹

**检测什么：** AI 生成的显微摄影或胶图往往"过于完美"。

**操作方法：**
1. 检查 WB 条带：是否所有条带都形态完美（无拖尾、无背景杂带）？
2. 检查显微图像：细胞形态是否存在违背物理规律的对称？
3. 检查图中是否出现毫无生物学意义的规则伪影（AI 生成的典型特征）
4. 用 Forensically 的 Noise Analysis 检查：AI 生成图的噪点分布往往呈现不自然的规律性

**红灯条件：**
- WB 条带形态与手工跑胶的实际特征明显不符（如边缘过于锐利、缺少渐变）
- 显微图像中存在生物学上不可能出现的结构或对称性

### 2.4 Forensically 自动化扫描

**工具：** [Forensically](https://29a.ch/photo-forensics/)（免费在线）

**操作方法：**
1. 打开 Forensically，上传论文中的关键图片
2. 依次使用以下功能：
   - **ELA (Error Level Analysis)：** 检测图片中不同区域的压缩率差异。拼接区域压缩率与周围不一致
   - **Clone Detection：** 自动检测图片中的克隆/复制区域
   - **Noise Analysis：** 检测噪点分布异常
3. 对飘红区域截屏存档

**判定：**
- ELA 显示某区域压缩率明显不同 → 该区域被后期修改过
- Clone Detection 自动标出重复区域 → 直接证据

**红灯条件：**
- Clone Detection 命中
- ELA 飘红区域恰好对应论文中的关键数据区域，且无合理解释

### 2.5 显微镜图像专项检查（生科专属）

**检测什么：** 免疫荧光/免疫组化/共聚焦/电镜图像的生物学真实性和跨图复用。

**操作方法：**

**比例尺核查：**
1. 在同一论文的不同显微图片中，定位比例尺（Scale Bar）
2. 测量比例尺的实际像素长度 → 换算到物理尺寸
3. 检查同一放大倍数的图片中比例尺是否一致
4. **红灯：** 同一论文声称相同放大倍数的图片，比例尺像素长度不一致

**荧光通道对齐检查：**
1. 在多通道合并图中（如 DAPI + GFP + Texas Red），分别截取各通道
2. 检查不同通道的细胞/组织轮廓是否完全一致
3. **红灯：** 不同通道的细胞核位置出现偏移 → 图像被后期移动/拼接

**跨论文复用：**
1. 将同一课题组/同一作者多篇论文中的显微图截图并排比对
2. 重点检查：细胞分布模式、组织切片形状、荧光亮点相对位置
3. **红灯：** 不同论文声称的不同实验条件下，显微图视野中细胞排列完全一致（尤其是"幸运视野"复用）

**生物学常识审查：**
- 细胞核大小是否在正常范围内（通常 5-15 μm）？
- 组织切片的形态结构是否与声称的组织类型匹配？
- 荧光信号是否出现在生物学合理的位置（如胞核标记物不应充满细胞质）？

**同视野不同荧光强度检测（抓人为制造差异）：**

造假手法：用同一只动物/同一组织切片，在不同显微镜设置下（改变 Gain、曝光时间、激光强度）拍摄多张图，声称是不同实验组的免疫荧光/免疫组化结果。形态学完全一致，只有荧光亮度不同。

操作：
1. 将同一论文中声称"不同处理组"的免疫荧光/免疫组化图并排比对
2. 重点观察：DAPI 染色的细胞核分布模式是否完全一致？
3. 叠加比对：用 Fiji/ImageJ 的 `Image → Overlay → Add Image` 将两张图叠起来 → 降低上层透明度
4. **红灯：** 两张声称不同实验组的图中，所有细胞的轮廓、位置、排列完全重合——这不是生物学重复，这是同一张切片拍了两次
5. **红灯：** 唯一的区别是荧光亮度/对比度，但细胞形态结构无任何变化（真实不同动物/不同切片的细胞排列必然有差异）

**特别注意：** 免疫电镜（Immuno-EM）图如果出现背景金颗粒分布完全一致、仅目标区域染色强度不同 → 同一张片子调了参数重拍，直接红灯。

### 2.6 流式细胞术图专项检查（生科专属）

**检测什么：** 流式散点图的门控（Gating）百分比自洽性和跨论文复用。

**操作方法：**

**百分比算术核查：**
1. 从流式图中定位各门控的百分比标注
2. 绘制门控层级树：父门 → 子门 → 子子门
3. 逐级验证：子门的百分比之和是否等于父门？
4. **红灯：** 子门百分比之和不等于父门（真实流式细胞仪不可能产生此结果）

**跨论文复用：**
1. 比对同一作者多篇论文中的流式散点图
2. 重点观察：散点分布形态（云状、密度集中区域）是否在多篇论文中出现完全相同的模式
3. **红灯：** 散点分布形态在声称的不同样本/不同条件下完全一致

**轴刻度检查：**
- 对数轴的刻度范围是否合理（通常 10⁰–10⁶）？
- 阴性群的荧光强度是否落在生物学合理的区间？

## Step 3 · 数字三角对账

> 造假者最难兼顾的就是让前后所有数字严丝合缝。只用简单的加减法就能找出破绽。

### 3.1 死磕 N 数（样本量溯源）

**检测什么：** Methods 声称的样本量 vs 实际图表中出现的样本数是否一致。

**操作方法：**
1. 从 Methods 中提取：总样本量、各分组样本量
2. 从 Table 1 中提取：各组基线数据对应的样本量
3. 从 Result Figures 中逐张检查：散点图点数、柱状图的 n 标注
4. 绘制流向图，记录每一步的样本增减

**典型的 N 数矛盾：**
- Methods："2025 年从随州中心医院和随县中医院共收集 68 例急性发热患者样本（32 例阳性，36 例未知）"
- 散点图：阳性组只有 28 个点
- 如果正文没有明确说明 4 个样本的剔除原因（如溶血、降解）→ **涉嫌 Cherry-picking**

**红灯条件：**
- 任意图表中实际出现的样本数 < Methods 声称的样本数，且未标注剔除原因
- 同一批样本在不同图表中数量不一致
- Table 1 分组总和 ≠ Methods 声称的总样本量

### 3.2 P 值反向验算

**工具：** [`statcheck`](https://github.com/MicheleNuijten/statcheck)（免费 R 包）/ [GRIM Test](http://nickbrown.fr/GRIM)（免费在线）

**操作方法：**
1. 从论文中提取：检验统计量（t 值、F 值、χ² 值）、自由度、报告的 P 值
2. 用 statcheck 重算：
   ```r
   library(statcheck)
   statcheck("paper.pdf")  # 自动提取并重算 APA 格式的统计报告
   ```
3. 手动复算：使用 R 的 `pt()`、`pf()`、`pchisq()` 函数
4. 对散点图：肉眼判断数据分散程度是否与声称的 P 值一致。高度重叠的散点图不应出现 P < 0.01

**判定：**
- 重算 P 值 > 0.05 但论文声称 P < 0.05 → **统计造假**
- 重算 P 值与论文报告值严重不一致（如论文报 P = 0.001，重算 P = 0.04）→ 标记可疑

**红灯条件：**
- statcheck 标记为 `Decision Error`（重算 P 值跨越 0.05 阈值）
- 手动重算 P 值与论文报告值不一致
- 散点图肉眼与 P 值不匹配

### 3.3 GRIM 检验

**检测什么：** 适用于整数型数据（样本量、人数、年龄等），检查描述统计是否存在数学矛盾。

**工具：** [GRIM Test](http://nickbrown.fr/GRIM)（免费在线）

**操作方法：**
1. 从论文中提取整数型变量的：均值(Mean)、样本量(N)
2. 输入 GRIM Test 页面
3. 工具自动判断：N 个整数能否算出报告的均值？

**原理：** N 个整数的均值，其小数部分必须符合特定的数学约束。例如，5 个整数的均值，其小数部分只能是 .0、.2、.4、.6、.8。

**红灯条件：**
- GRIM 检验返回 `Inconsistent`——报告的均值在数学上不可能来自 N 个整数

### 3.5 本福特定律检验（大规模数据打假）

**检测什么：** 针对论文中跨度几个数量级的连续型数据集——如 Supplementary 中的自测测序表达矩阵、大规模流调问卷生化指标汇总表、几百个样本的基线数据表。传统 statcheck 和 GRIM 只能查小样本统计量，这里查的是原始数据本身是否被 Excel RAND() 或手工键盘编造。

**工具：** R / Python（免费）/ [在线本福特计算器](https://faculty.washington.edu/tozer/benford.html)

**原理：** 真实世界的高通量数据（如基因表达值、生化指标浓度、人口统计数值），其首位数字遵循本福特定律——1 开头的概率约 30%，9 开头的概率不到 5%。如果造假者用 Excel 的 `RAND()` 函数或手工编造几千个数值，首位数字 1-9 的分布通常是均匀的（各约 11%）。

**操作方法（R）：**
```r
# 从论文 Supplementary Excel/CSV 中提取数值列
data <- read.csv("supplementary_table.csv")
values <- as.numeric(data$expression_level)  # 替换为实际列名

# 提取首位数字
first_digits <- as.numeric(substr(abs(values), 1, 1))
first_digits <- first_digits[first_digits >= 1 & !is.na(first_digits)]

# 计算实际分布
observed <- table(first_digits) / length(first_digits)

# 本福特理论分布
benford <- log10(1 + 1/1:9)

# 对比
comparison <- rbind(observed, benford)
print(round(comparison * 100, 1))

# 卡方检验
chisq.test(observed * length(first_digits), p = benford)
```

**判定：**
- 首位数字 1 的占比约 25-35% → 符合自然数据特征
- 首位数字 1-9 均匀分布在 8-14% → Excel RAND() 或键盘编造嫌疑
- 卡方检验 P < 0.01 且分布偏离方向为"均匀化"→ 数据伪造概率极高

**适用条件：**
- 数据跨度至少 2-3 个数量级（如 10 到 10000），单一数量级数据不适合
- 样本量至少 100 个数值以上，越多越可靠
- 不适用于：分配的编号/ID、电话号码、邮政编码等非自然数值

**红灯条件：**
- 首位数字分布接近均匀（各 8-14%）而非本福特分布（1 占 ~30%，9 占 ~5%）
- 卡方检验拒绝本福特分布 + Supplementary 中无对此偏差的合理解释

**假阳性防护 · 组学数据标准化陷阱：**

处理大规模组学数据时需严格区分原始数据和已转换数据：

- 经过高度标准化处理的数据（如 Log2 转换后的表达值、Z-score 标准化值、TPM/RPKM 归一化值）往往会自然偏离本福特定律——这不是造假，是数学转换的必然结果
- **本福特定律应仅应用于：** 原始读取计数（Raw Counts）、基础人口统计学指标（年龄、收入）、未经非线性转换的生化浓度数值（如血糖 mg/dL、血红蛋白 g/dL）
- **不应用于：** 任何经过 Log 转换、Z-score 标准化、分位数归一化、批次效应校正后的数据
- **判定原则：** 若无法确认 Supplementary 表格中的数据是否为原始数值 → 跳过本福特检验，不强行应用。宁可漏过一个真造假，不能误伤一篇真论文

### 3.4 Table 1 基线平衡检查

**检测什么：** 随机化分组后，基线变量是否"过于完美"？

**操作方法：**
1. 找到 Table 1（干预组 vs 对照组的基线特征对比）
2. 检查各组标准差/标准误：如果各组 SD 几乎完全相同 → 伪造嫌疑
3. 检查 P 值模式：如果所有基线变量的组间比较 P 值都 > 0.05 且集中于 0.5-0.9 → 过于完美
4. 检查连续变量的小数位：是否所有数字都整齐地结束了相同的位数？

**判定：**
- 真实随机化：会有偶然的不平衡，SD 有自然波动
- 伪造数据：SD 整齐划一，P 值过于集中，小数位过度整齐

**红灯条件：**
- 多组 SD 完全相同或极其接近
- 基线变量 P 值呈现非自然分布（如全部介于 0.6-0.9 之间）
- 多位小数呈现异常的一致性

### 3.6 动物实验曲线审查（生科专属）

**检测什么：** 肿瘤生长曲线、体重变化曲线、生存曲线的"人为修饰"痕迹。

**操作方法：**

**肿瘤体积/体重曲线平滑度审查：**
1. 找到肿瘤生长曲线图或动物体重变化图
2. 观察曲线的波动程度：真实实验数据由于测量误差、个体差异，曲线应有自然的锯齿波动
3. **红灯：** 曲线过于平滑——几乎没有人看到测量点偏离趋势线——这是 Excel 手工绘制或公式生成的典型特征
4. **红灯：** 不同处理组曲线形态完全相同、仅在 Y 轴方向平行移动（造假者复制同一组数据后统一加减一个常数）

**误差棒一致性：**
- 检查各时间点误差棒（SEM/SD）的大小是否合理
- 真实实验：随肿瘤体积增大，误差通常也随之增大（异方差性）
- **红灯：** 各时间点误差棒大小几乎一致，或后期肿瘤很大但误差很小

**生存曲线审查：**
1. 观察生存曲线的阶梯状下降模式
2. 真实临床生存数据：事件发生时间随机，阶梯分布不均匀
3. **红灯：** 生存曲线出现规律性阶梯（如每隔固定时间恰好有 1-2 个事件）→ 手工编造事件时间的典型特征
4. **红灯：** 多条生存曲线形状高度相似但在特定时间点"神奇地"分离——可能为人为调整

### 3.7 剂量-反应曲线审查（生科专属）

**检测什么：** 伪造的剂量-反应曲线与真实实验数据的形态差异。

**操作方法：**
1. 定位药物/化合物浓度-效应曲线（如 IC50 图、浓度-抑制率图）
2. 观察数据点分布：
   - 真实实验：数据点有自然离散，平台期有波动，Hill 斜率合理
   - 伪造数据：数据点几乎完美贴合 S 形曲线，无任何离散
3. **红灯：** 各浓度点的误差棒大小几乎完全相同——真实实验中低浓度和高浓度的误差通常不同
4. **红灯：** 浓度跨 5-6 个数量级但每个数量级只有 1 个点，且全部点完美落在曲线上
5. **红灯：** Hill 斜率异常（绝大多数药物 Hill 斜率在 0.5-2 之间，过高的 Hill 斜率暗示人为构造）

**IC50 反推验证：**
- 如果论文报告了 IC50 值 → 在图上标注 IC50 对应的浓度位置
- **红灯：** 图中标注的 IC50 值与曲线实际交叉 50% 抑制率的位置不一致

### 3.8 组间数据算术关系检测（生科专属）

**检测什么：** 造假者编造多组数据时，常偷懒对一组数据做简单的加减乘除来生成另一组。真实生物学实验中，不同处理组的测量值之间几乎不会出现精确的算术关系。

**操作方法：**
1. 从论文 Supplementary 表格中提取各组的连续型数据（如基因表达值、生化指标、细胞活力%）
2. 计算组间比值：Group B / Group A、Group C / Group A
3. 检查比值是否异常恒定：
   ```r
   ratio <- group_B / group_A
   sd(ratio)  # 比值标准差
   ```
4. 计算组间差值：Group B - Group A，同样检查差值是否异常恒定

**判定：**
- 所有配对比值完全相同（如 Group B 始终 = Group A × 1.32）→ **手工公式生成**，真实实验不可能
- 所有配对差值完全相同时 → 同上
- 比值变异系数（CV）< 1% 且跨几十个独立样本 → **数据伪造**
- 真实实验中，不同样本的个体差异会导致比值有一定波动

**常出现的场景：**
- Western Blot 灰度定量：NC 组条带灰度值全部恰好是对照组的 50%
- CCK-8 细胞活力：药物处理组活力 = 对照组 × 0.6 ± 0.001（变异极小）
- qPCR 相对表达量：siRNA 组表达量全部恰好是对照组的 0.3 倍

**红灯条件：**
- 组间比值变异系数 < 1%，且 n ≥ 10
- 任意两组间存在精确的常数倍数关系（如 Y = 1.500 × X 对所有样本成立）

### 3.9 尾数偏好与小数位一致性（生科专属）

**检测什么：** 造假者手工编造数据时，常不自觉地偏好某些尾数（如 0 和 5），且不同变量的小数位精度不一致。真实测量数据：尾数 0-9 均匀分布（各约 10%），同表内小数位数一致。

**操作方法：**

**尾数分布分析（R）：**
```r
# 提取所有数值的最后一位有效数字
values <- na.omit(as.numeric(as.matrix(supp_table)))
last_digits <- as.numeric(sub(".*\\.", "", as.character(values)))
last_digits <- last_digits[!is.na(last_digits) & last_digits >= 0 & last_digits <= 9]

# 频数分布
observed <- table(factor(last_digits, levels = 0:9))
expected <- rep(length(last_digits) / 10, 10)

# 卡方检验
chisq.test(observed, p = rep(1/10, 10))

# 可视化
barplot(observed / sum(observed), names.arg = 0:9,
        main = "Last Digit Distribution",
        ylab = "Proportion", ylim = c(0, 0.2))
abline(h = 0.1, lty = 2, col = "red")  # 期望线
```

**判定：**
- 某尾数占比 > 20% 或 < 3% → 人为偏好
- 常见人为偏好尾数：0（占比常 > 25%）、5（> 20%）、偶数尾数偏多
- 卡方检验 P < 0.001 且偏离方向为 0、5 过度出现 → **手工编造数据**

**小数位一致性检查：**
1. 扫描同一表格中同一类型变量的所有值
2. 提取小数位数：`nchar(sub(".*\\.", "", as.character(value)))`
3. **红灯：** 同一列数据中，部分值保留 1 位小数、部分保留 3 位小数（如 23.1、17.435、9.8、31.22 混在同一列）→ 正规数据录入不会有这种不一致
4. **红灯：** 不同组但同一变量的报告精度不同（如对照组均值 23.45 ± 2.1，实验组均值 17.3 ± 3.876）

**红灯条件（综合）：**
- 尾数卡方检验 P < 0.001 + 0 和 5 合计占比 > 35%
- 同一列数据小数位数不一致（≥ 3 种不同精度）
- 组间同一变量报告精度不一致

### 4.4 组学多重比较校正检查（生科专属）

**检测什么：** 大规模差异分析（转录组、蛋白组、代谢组、宏基因组）中，未做多重比较校正的"显著"结果泛滥。在同时检验数千个基因/蛋白/代谢物时，不做校正就使用 P < 0.05 → 假阳性率极高。

**操作方法：**
1. 定位论文 Methods 中"Statistical Analysis"或"Differential Expression Analysis"段落
2. 搜索是否出现以下关键词：
   - `FDR` / `false discovery rate` / `Benjamini-Hochberg`
   - `Bonferroni correction` / `Bonferroni`
   - `adjusted P value` / `Padj` / `q-value`
   - `multiple testing correction` / `multiple comparison correction`
3. 如果 Methods 中声称做了校正 → 检查 Results 中报告的 P 值是**原始 P 值**还是**校正后 P 值/adj.P/q-value**
4. 检查火山图/热图：差异基因筛选阈值是否基于校正后 P 值（如 adj.P < 0.05）而非原始 P 值（P < 0.05）

**判定：**
- 同时检验 > 100 个基因/蛋白，Methods 未提及任何多重比较校正方法 → **统计学根本性错误**，所有"显著差异"结果不可信
- Methods 声称做了 FDR 校正但 Results 报告的 P 值都集中在 0.001-0.01（校正后 P 值通常比原始 P 值大很多，很难出现大量 0.001）→ 疑似仍使用原始 P 值
- 火山图中使用 `P < 0.05` 而非 `adj.P < 0.05` 作为阈值 → **红灯**

**分级判定：**
- 仅在 Methods 中宣称"P < 0.05 was considered statistically significant"且未提及校正 → **该论文所有组学差异分析结论存疑**
- 如果同时发现：未校正 + 所有 Top 基因恰好是课题组已发表通路中的基因 → 高度疑似 Cherry-picking

### 4.5 RNA-seq 归一化数学关系验证（生科专属）

**检测什么：** RNA-seq 数据的 RPKM/FPKM/TPM 值是通过固定数学公式从 Raw Counts 计算来的。造假者如果编造了 Count 或表达值但不懂归一化公式，数学关系会断裂。

**原理（必检关系式）：**

1. **RPKM 定义：**
   ```
   RPKM = (Count × 10⁹) / (Total_Mapped_Reads × Gene_Length_bp)
   ```
   因此对于同一基因：`Count / Gene_Length` ∈ 常数 × RPKM

2. **TPM 定义：**
   ```
   TPM = (RPKM_gene / Σ_RPKM_all) × 10⁶
   ```
   因此：`Σ_TPM_all_genes` 必须 = 10⁶

3. **关键不变量：** 对于同一 RNA-seq 样本的不同基因：
   ```
   Count_A / Count_B ≠ RPKM_A / RPKM_B  （除非基因长度相同）
   ```
   即：Count 值之间的比值与 RPKM 值之间的比值通常不同（受基因长度影响）。

**操作方法：**
1. 从论文 Supplementary 中找到 RNA-seq 表达矩阵（必须同时包含 Count 和 RPKM/FPKM/TPM 列）
2. 计算比值验证：
   ```r
   # 每个基因的 Count / Gene_Length 是否与 RPKM 成正比？
   count_per_length <- count / gene_length_bp
   rpkm_ratio <- count_per_length / rpkm
   sd(rpkm_ratio)  # 应该接近 0（同一批次内为常数）
   ```
3. TPM 总和检查：
   ```r
   sum(tpm_values)  # 必须 = 1,000,000（或接近）
   ```

**判定：**
- `Count / Gene_Length` 在同一 RNA-seq 样本的不同基因间不是常数 → **Count 或 RPKM 值是编造的，不懂归一化公式**
- TPM 总和严重偏离 1,000,000 → TPM 值伪造
- Count 值相对大小与 RPKM 值相对大小完全一致（如都显示 Gene X 是 Gene Y 的 2.3 倍）→ **造假者直接把 Count 乘以常数当成了 RPKM，不懂基因长度校正**

**红灯条件：**
- `Count / Gene_Length` 跨基因的变异系数 > 5%
- TPM 总和偏离 10⁶ 超过 1%
- Count 比值 = RPKM 比值（对所有基因对成立）→ 直接乘以常数伪造
- 论文声称做了 RNA-seq 但 Supplementary 中只有一种表达值（仅有 RPKM 或仅有 Count）且无基因长度信息 → 不可复现

**红灯条件：**
- Discussion 全文 AI 概率 > 80%
- 文字空洞（每段都在重复结果但不讨论机制、局限、对比文献），结合高 AI 概率

**假阳性防护 · 非母语英语使用者（Non-native Speaker）偏见：**

目前学界共识是 GPTZero 等 AI 检测工具对非母语英语使用者极不友好。非母语者为了追求学术规范，往往会使用高度结构化、词汇单一的句式——这恰好是 AI 检测器判定"高风险"的信号特征，而非实际使用了 AI。

- **AI 概率扫描仅作为参考，绝对不应作为任何级别的实锤证据**
- 高 AI 概率 + 黑名单词命中 + 内容空洞 → 可疑但不足定罪
- 高 AI 概率但内容有实质性的机制讨论、文献对比、局限性分析 → 大概率是非母语者正常写作
- **真正具有杀伤力的文本证据仍然是：** 5.1 黑名单词命中 + 5.3 结果-讨论矛盾 + 5.3.1 P 值伪装话术。AI 概率分数只是辅助参考，不改变判定权重

### 5.3 自相矛盾的讨论

**检测什么：** Results 中的阴性/不显著结果，在 Discussion 中是否被刻意忽略或强行解释为阳性支撑？

**操作方法：**
1. 列一个两栏表：
   - 左栏：Results 中每个明确的统计检验结果及 P 值
   - 右栏：Discussion 中对每个结果的描述
2. 逐条比对：
   - 不显著结果是否被描述为 "trend towards significance"？
   - 阴性结果是否在 Discussion 中完全消失？
   - 次要结果是否被拔高为核心发现？

**5.3.1 P 值 Hacking 的语言学伪装（高杀伤力）：**

**检测什么：** 当真实 P 值在 0.051 到 0.09 之间时，作者不愿承认失败，用特定话术强行暗示两组有差异。

**操作方法：** Ctrl+F 全文搜索以下短语（不区分大小写）：

| 伪装话术 | 实际含义 |
|---|---|
| `trending towards significance` | P > 0.05，不显著 |
| `marginally significant` | P > 0.05，不显著 |
| `almost significant` | P > 0.05，不显著 |
| `approached significance` | P > 0.05，不显著 |
| `borderline significant` | P > 0.05，不显著 |
| `trend towards` | P > 0.05，不显著 |
| `nominally significant` | 通常是 P 在 0.01-0.05 之间但经过了多重比较校正后不再显著 |

**判定：** 在严谨的统计学语境下，没有"差点怀孕"这种事。只要 P > 0.05，在 Discussion 中就必须按"无统计学差异"处理。使用上述任何话术来暗示组间差异 → 统计学违规。

**红灯条件（5.3 综合）：**
- 命中 ≥ 1 个 P 值伪装话术（trending towards / marginally / almost / approached / borderline significant）且对应 P 值实际 > 0.05
- ≥ 2 个不显著结果被描述为"显著趋势"或"边缘显著"
- 阴性/不显著结果在 Discussion 中完全不被提及
- Results 中的次要/探索性分析在 Discussion 中被包装为主要结论

### 红灯累积规则

| 红灯组合 | 判定 | 建议行动 |
|---|---|---|

| 仅 Step 5 红灯（AI 文本）| **质量问题但不等于造假** | 标记但不必定论，注意非母语者假阳性。重点看数据层面有无更多问题 |

### 证据收集清单

当发现红灯时，系统性记录以下内容：

1. **截图：** 原图 + 分析后的对比图（标注异常位置）
2. **页码和位置：** 每个异常的精确 PDF 页码、图号、段落位置
3. **复现步骤：** 写下你的操作步骤，让别人可以重复你的发现
4. **时间戳：** 所有操作的时间记录（证明分析的时效性和连续性）
5. **原始 PDF：** 保留下载时的 PDF（MD5 哈希固化，证明你分析的就是这个版本）

## 检测边界（诚实声明）

以下造假手段**无法**仅凭论文 PDF 检出：

| 造假手段 | 为什么检不出 | 需要什么才能检出 |
|---|---|---|
| 数据完全伪造但内部统计自洽 | 伪造者确保了前后数字一致，数学上挑不出错 | 原始数据 + 实验室记录 |
| 论文工厂专业出品 | 无拼接、无复用、AI 痕迹自然、代码公开且跑通 | 物理样本核实 + 财务审计 |
| 代码未公开 | Step 4 完全无法执行 | GitHub 链接或作者配合 |
| 数据非来自公共数据库 | Step 4.2 无法执行 | 作者提供原始数据 |
| 原始图像未在论文中展示 | 只能分析已发表的图像 | 原始仪器文件 |

**诚实原则：** 本 Workflow 能检出大部分"粗放型"造假，但无法替代机构层面的系统性审查。遇到无法确定的标记项，标注为"疑点"而非"造假"——保持与证据强度匹配的表述。

## 快速核查清单（一页纸）

拿到一篇论文，逐项打勾：

**Step 1 · 逻辑与动机（5-10 分钟）**
- [ ] 核心假说在已知文献中有支撑？
- [ ] 结论未超出实验材料的能力范围？
- [ ] 因果断言均有实验证据标注？
- [ ] 关键抗体/试剂盒均有货号（Catalog Number）/RRID？

**Step 2 · 图像法医学（20-40 分钟）**
- [ ] Forensically Clone Detection：无命中？
- [ ] 暴力调对比度后无噪点断层？
- [ ] LUT 伪彩映射（Fire/Royal）无"贴邮票"矩形纯色框？（注意 PDF 压缩伪影）
- [ ] 内参条带（GAPDH/β-actin）无跨 Panel 复用？
- [ ] 显微镜：同倍率比例尺像素一致？荧光通道对齐？
- [ ] 显微镜：不同处理组 IF/IHC 图细胞排列不完全重合（非同一切片重拍）？
- [ ] 流式：门控百分比子层级之和 = 父层级？
- [ ] 无 AI 生成的"过于完美"特征？

**Step 3 · 数字对账（20-40 分钟）**
- [ ] Methods → Table 1 → Figures → N 数一路自洽？
- [ ] statcheck 无 Decision Error？
- [ ] GRIM 检验无 Inconsistent？
- [ ] 尾数 0-9 分布均匀（无 0、5 偏好）？同一列小数位数一致？
- [ ] 本福特定律：大数量级原始数据首位数字分布正常？（注意标准化数据不适用）
- [ ] 组间数据无精确常数倍关系（如 Group B ≠ Group A × 1.5 对所有行成立）？
- [ ] Table 1 基线数据 SD/小数位自然？
- [ ] 动物曲线：肿瘤体积/体重曲线有自然波动（非过度平滑）？
- [ ] 剂量-反应曲线：数据点有合理离散（非全部贴合 S 形）？

**Step 4 · 代码与公开数据（如有，30 分钟+）**
- [ ] 代码中无硬编码无注释的数据剔除？
- [ ] 独立下载同批次公开数据，底层分布对得上？
- [ ] 有环境锁文件，代码可运行？
- [ ] 组学差异分析 Methods 中明确写了 FDR/Bonferroni 校正方法？
- [ ] RNA-seq：Count/Gene_Length 跨基因变异系数 < 5%？TPM 总和 ≈ 10⁶？

**Step 5 · 文本排查（10-15 分钟）**
- [ ] 黑名单词命中 < 3 个？
- [ ] GPTZero AI 概率仅作参考（注意非母语者假阳性），AB 则不必定论？
- [ ] 无 P 值伪装话术（trending towards / marginally / almost / borderline significant）？
- [ ] Results 中阴性结果在 Discussion 中未被忽略或歪曲？
