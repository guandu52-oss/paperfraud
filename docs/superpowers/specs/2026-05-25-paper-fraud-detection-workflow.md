# 学术论文防造假审查 Workflow — 实操版

## 总览

四阶段全生命周期审查：日常数据管理 → 撰写前自查 → 终审关卡 → 舆情应急。核心理念：**机器扫雷，人工只看红灯；每一步留痕，数据冷冻留底。**

| 阶段 | 时间 | 谁执行 | 做什么 |
|---|---|---|---|
| Phase 1 · 日常数据管理 | 持续进行 | 学生 + PI | ELN 记录、图像归档、代码存档、样本入库 |
| Phase 2 · 撰写前自查 | 投稿/送审前 2-4 周 | 学生自查 + PI 签字 | 图像/统计/样本/AI 文本/投稿合规 —— 五维自查 |
| Phase 3 · 终审关卡 | 送审/答辩前 1 周 | 学术诚信委员会 | 9 件套材料 + 红绿灯分级 + 数据冷冻 |
| Phase 4 · 舆情应急 | 舆情触发时 | 院长 + 党委书记 | 冷冻档案调取 + 分级回应 + 制度补丁 |

**费用原则：** 所有检测工具（NAS、ImageTwin、GPTZero、ELN）由学院承担，不转嫁学生。

---

## Phase 1 · 日常实验数据管理

### 1.1 电子实验记录本 (ELN)

**工具：** Benchling / LabArchives / RSpace

- 允许拍照上传手套速记、纸质草稿等"脏数据"
- 每周五前或组会前集中整理本周核心数据
- 产出可用结果的实验必须补齐试剂批号和操作步骤
- 每季度 PI 抽查，学院随机抽 10% 检查完整性

### 1.2 图像与结果归档

**工具：** Synology Drive / NextCloud（部署于公共仪器电脑后台）

- 公共仪器（凝胶成像仪、显微镜）后台静默同步，学生点保存即可
- 原始格式（TIFF/CZI/ND2）自动上传至学院 NAS 个人文件夹，学生无删除权限

**NAS 防篡改：**
- Drop Zone（写入区）：仅可追加，不可删除/覆盖
- 定时搬移脚本 → Archive（只读归档区），按 课题组/仪器/日期 分类
- NAS 每日自动打不可变快照

### 1.3 代码与数据管理

**工具：** Git（学院 GitLab 实例）

- 平时怎么写不管。生成用于论文的图表时，必须打包存档：图 + 最终代码 + 清洗后数据
- 提交物：代码 + `sessionInfo()` / `renv.lock` + `requirements.txt`
- 只审查最终代码能否一键复现，不审查中间试错过程

### 1.4 样本入库

- 高优样本（临床血清、核心结论相关）：双人核对签字，数量精确
- 大批量样本：预制二维码冻存管，批量扫码入盒，系统自动生成含时间戳的清单

## Phase 2 · 撰写前数据自查

### 2.1 图像完整性自查

**工具：** Forensically（免费，学生自扫）→ ImageTwin / Proofig（收费，学院批量扫）→ Fiji/ImageJ（EXIF 提取）

**流程：**
1. 学生用 Forensically 自扫全部图片（ELA + 克隆检测 + 噪声分析），提交截图
2. 学院用 ImageTwin 批量扫拟送审论文
3. 假阳性豁免：学生对飘红区域写一句批注即可（如"统一基线对照"）
4. EXIF 元数据兜底：校验设备型号、拍摄时间、曝光参数。缺失或不匹配 → 标记可疑
5. 哈希比对：论文图片 ↔ NAS 原始文件 ↔ SHA-256 一致

### 2.2 统计结果复现（截断式）

**不要求从 FASTQ 从头跑。** 学生提交中间态清洗数据作为复现起点，系统只跑最后一步——生成 Table 1、生存曲线、核心统计检验的代码（通常几分钟跑完）。

**判定：**
- 代码跑不出论文数字 → 退回重做
- 跑出结果与论文不符 → 启动调查
- 检测到无注释的数据剔除 → 必须提供书面理由

### 2.3 样本量溯源

**三方交叉核对：** ELN 入库记录 vs 分析代码纳入数 vs 论文声称数

**必附样本流向图（5 分钟可完成）：**
```
总样本 n=68（随州中心医院 45 + 随县中医院 23）
  ├─ SFTSV 阳性 n=32
  │    ├─ 纳入分析 n=30 ← 论文报告这个数
  │    └─ 剔除 n=2（溶血标本，编号 SFTS-017/038）
  └─ 未知病原 n=36
       ├─ 纳入分析 n=36
       └─ 剔除 n=0
```

**铁律：** ELN 记录 ≥ 代码纳入 ≥ 论文声称，中间有差额必须标注原因。差一个数 → 退回重改。

### 2.4 Motivation 答辩 + Overclaim 审查

**时机：** 论文初稿完成后，组会 15 分钟陈述

**四个必答问题：**
1. 这个科学问题是真的存在，还是为了用某个技术编出来的？
2. 如果结果全部推翻重来，这个研究方向本身还成立吗？
3. 你的结论如果错了，会有人在意吗？
4. 你的结论边界在哪里？—— 模型生物验证的，别说成人群普遍规律；相关性发现，别说成因果机制

**因果断言标注规则：** 论文中任何声称因果关系的句子，必须标注对应实验证据编号。如："A activates B (Fig. 3C-D, Co-IP; Fig. 4A, WB; Fig. S2, Confocal)"。无标注的因果断言 → 退回补证据或降级为相关性表述。

**判定：** PI + 课题组全员在场，至少两人提出质疑并获合理解答，PI 签字通过。

### 2.5 AI 文本痕迹与浮夸词排查

**Step 1 · 机器预扫：** GPTZero 全文扫描，重点盯 Abstract 和 Discussion

**Step 2 · 关键词黑名单（Ctrl+F）：**

| 黑名单词 | 原因 |
|---|---|
| revolutionary | AI 偏好浮夸修饰 |
| undoubtedly / without any doubt | 同上 |
| first-ever / completely novel | 无法验证的绝对化声称 |
| solves / resolved | 单个研究很少能"solve"一个领域问题 |
| opens a new era / unprecedented / paradigm shift | AI 偏好的空洞宏大叙事 |

已移除 `proves / proved / demonstrate` —— 多实验正交验证（WB + Co-IP + 共聚焦指向同一结论）时使用合理。

**Step 3 · 判定：** Abstract / Discussion 命中 ≥ 3 个黑名单词 → 自动打回降温修改。

### 2.6 投稿合规审计

**先审后投铁律：** 院长签字生效前，论文不得进入任何期刊投稿系统。若投稿时间早于院长签字时间 → **直接冻结 6 个月 + 全院通报。**

**投稿前规则：**
- 通讯作者必须使用 `@xxx.edu.cn` 邮箱投稿，禁止 Gmail/163/QQ
- 投稿后将确认信截图（Manuscript ID + 时间戳 + 投稿 IP）交秘书处归档
- 投稿 IP 核查：作者人在武汉，投稿 IP 长期在境外/代写黑产活跃地区 → 红灯

### 2.7 外包实验边界

**白名单（可外包，须留痕）：**

| 可外包类型 | 必须提交的凭证 |
|---|---|
| 测序服务 | 原始下机数据 + FastQC 报告 + 公司盖章交付单 |
| 商业化试剂/耗材 | 采购记录（货号、批次、购买日期）|
| 第三方检测（质谱、电镜、病理切片）| 原始报告 + 原始数据文件 |
| 动物饲养/繁育 | 饲养合同 + 基因型鉴定报告 |
| 通用生信分析 | 代码 + 中间态清洗数据 |

**黑名单（必须课题组亲自完成）：**
- 论文核心结论依赖的关键实验（Co-IP、Western Blot 关键条带、活体动物感染模型）
- 临床样本采集与处理
- 原始数据统计分析
- 论文撰写

**交叉锁死：** Phase 3 审查时核验——凡论文涉及黑名单中的核心实验，必须在 NAS 归档区中提取到本院仪器生成的、带时间戳的原始底层数据（TIFF/CZI/ND2）。拿不出来 → 需提供合作单位书面证明 + 对方仪器原始数据。两者都没有 → **判定为违规代做。**

### 2.8 PI 胁迫学生造假的处理

**保护学生就是保护学院名声。** 学生不因服从 PI 的造假指令而承担学术不端责任。

| 场景 | 处置 |
|---|---|
| 学生能证明违规操作是 PI 指令 | 学生免予追责，责任归于 PI |
| PI 口头指令，无书面记录 | 学生在意识到指令违规后 7 日内向党委书记补录陈述（时间戳 + 录音），作为保护性证据存档 |
| 学生因拒绝 PI 造假指令遭报复 | 触发举报人保护机制，党委书记介入 |

### 2.9 预印本处理

上传预印本 = 进入公共领域 = 必须经过 Phase 2 审查。预印本上传前至少完成 Phase 2，上传后补完 Phase 3。未审查即上传 → PI 在 30 天内补走 Phase 2。逾期 → 论文冻结 3 个月。

## Phase 3 · 终审关卡

### 3.1 委员会架构

**6 人：** 院长（主持 + 学术终审 + 签字）、党委书记（纪律监督，不参与学术投票）、分管科研副院长、统计/生信负责人（Step 1 核心执行人）、学术委员会秘书（流程与档案）、轮值院外专家 1 名（从 20 人专家池随机抽取）。

**回避制度：** PI/通讯作者为委员会成员 → 强制退出本次审查。回避记录写入审查档案，对外可查。

**议事规则：** 学术投票全票通过制（4 票全部同意方可送审），反对意见须附书面理由。

### 3.2 终审材料清单（9 件套）

| # | 材料 | 要求 | 校验人 |
|---|---|---|---|
| 1 | 论文终稿 | PDF 含全部图表和 Supplementary | 秘书 |
| 2 | Phase 2 自查报告包 | ImageTwin/Forensically 截图 + 代码复现比对 + 样本流向图 + Motivation 记录 | 秘书 |
| 3 | 原始图像路径清单 | 每张图对应 NAS 路径 + SHA-256 | 生信负责人抽查 20% |
| 4 | 代码 + 环境锁 | 最终代码 + sessionInfo()/renv.lock + 清洗后数据 | 生信负责人 |
| 5 | 样本管理台账 | ELN 记录 + 样本流向图 + Table 1 核对表 | 秘书 |
| 6 | AI 文本扫描报告 | GPTZero + 黑名单自查结果 | 秘书 |
| 7 | PI 预审签字单 | 导师对以上 6 项逐项签字 | 秘书 |
| 8 | 投稿确认信截图 | Manuscript ID + 时间戳 + 投稿 IP + 通讯邮箱 | 秘书 |
| 9 | PI 经费自查报告 | PI 从财务系统导出《近两年测试化验加工费与版面费明细》+ 签字的《外包服务合规承诺书》 | 秘书核查是否提交 |

缺一件 → 退回补齐。48 小时未补 → 自动冻结。

### 3.3 红绿灯分级

**Step 1 · 硬核排雷（秘书 + 生信负责人，1-2 个工作日）：**

秘书：材料齐全性、ImageTwin 飘红是否有解释、AI 黑名单命中数、样本数字自洽、投稿邮箱/IP 合规、PI 经费报告已提交

生信负责人：代码独立运行 + 机器比对统计量差异率、抽查 20% NAS 路径哈希一致性

**红绿灯判定：**

| 灯 | 条件 | 处置 |
|---|---|---|
| 🟢 绿灯 | 图片无飘红 · 代码统计量一致 · 样本数字咬合 · 黑名单词 ≤2 · 投稿邮箱/IP 正常 · 无异常财务 | 快速通道，批量签字 |
| 🟡 黄灯 | 已解释的飘红 / 轻微数字偏差可合理解释 / IP 属地有波动但可解释 | 委员关注 |
| 🔴 红灯 | 未解释的拼接 / 代码 p 值对不上 / 样本数不一致 / 黑名单词 ≥3 / 非 @edu.cn 投稿 / IP 异常 / 可疑财务交易 | 触发实质性审查 |

**Step 2 · 分级审查：**
- 全绿灯 → 4 位学术委员传阅报告 + 审视 Discussion Overclaim → 批量签字
- 黄灯/红灯 + 随机抽查 10% → 全体闭门审查 + 院外专家 2 日内回复

**委员审查表（一页纸三个勾）：**
1. 是否发现无法解释的数据异常？□是 □否
2. 论文结论是否超出证据支持范围？□是 □否
3. 是否同意送审？□同意 □不同意（须注明具体问题）

**Step 3 · 质询与裁决（红灯触发）：** 委员会召集学生 + PI 当面质询 → 重新投票 → 仍不通过 → 冻结 6 个月；明确造假 → 直接升级校级学术道德委员会。

### 3.4 分级处置

| 等级 | 场景 | 处置 |
|---|---|---|
| 🟡 轻微 | 绝对化表述未修正、黑名单词略超标但语义合理 | 48h 修改 → 复核 → 通过 |
| 🟠 中等 | 代码无法复现核心结果、多图原图缺失、样本量多处不一致 | 冻结 6 个月 → PI 监督整改 → 重走全流程 |
| 🔴 严重 | 明确图像拼接、数据篡改、样本量蓄意造假、物理样本缺失 | 上报校级 → 学术不端调查 |
| ⚫ 论文工厂 | 全绿灯但物理/财务穿透发现全面造假 | 上报校级 + 通报公安机关 |

学生申诉：论文被冻结后可三级递进申诉（委员会复议 → 院长复核 → 校级申诉）。若被冻结原因非学生本人问题，可申请数据剥离单独撰写学位论文。

PI 本人涉假时：党委书记自动升级为调查主持人，不经过学院层面裁决，直接上报校级学术道德委员会。

### 3.5 院长签字背书

签字前确认：4 位学术委员均同意、党委书记无合规异议、全部材料已归档。

> "经学院学术委员会审查，该论文所涉实验数据、分析代码及原始记录已通过全流程核查。如论文发表后出现学术不端指控，本审查记录将作为调查依据对外提供。"

### 3.6 数据冷冻

**触发：** 院长签字生效后立刻执行。9 项材料全量打包为 Zip → SHA-256 → 存独立只读分区。可选区块链存证（仅哈希上链）+ 云温备份（WORM 锁，保留 10 年）。

**防什么：** 五年后举报 → 调压缩包 → 哈希一致 → 原图说话。原图完好 → 对外公布，举报不攻自破。确实造假 → 压缩包本身就是追责证据链。

### 3.7 物理实体与凭证穿透审查

**核心逻辑：** 论文工厂能编完美数据，但变不出物理样本、动物、试剂发票。从全绿灯论文中随机抽取 10% 执行。

**① 生物样本物理核实：**
- 临床患者样本 → 实地查看对应编号冻存管是否物理存在
- 动物模型 → 调取动物房饲养记录、伦理审批原件、动物采购凭证
- 细胞系 → 核对购买记录/赠予协议 + 液氮罐冻存位置
- 实物缺失 → 直接启动学术不端调查

**灭失物证替代凭据：** 活体动物已处理 → 动物无害化处理登记表；组织/RNA/DNA 已消耗 → 测序公司交付的原始数据报告 + 质检单；血清/冻存管 → 必须物理存在。

**② 试剂耗材与测序费用比对：** 论文声称提取 n 个样本 RNA 做全转录组测序 → 核对试剂盒采购记录 + 测序服务发票。消耗与采购记录严重不符 → 红灯。

**③ 合作单位交叉验证：** 多中心临床样本 → 联系合作医院核实。合作方不知情或否认 → 严重造假，上报校级。

**执行：** 秘书提前 48 小时通知，PI 陪同但由委员会成员亲自查看实物和原始记录，拍照存档。

### 3.8 财务报销异常拦截

**PI 自行导出 + 签字承诺（举证责任倒置）：** PI 登录财务系统导出《近两年测试化验加工费与版面费明细》+ 签署《外包服务合规承诺书》。

秘书仅检查是否提交。委员会 Step 2 若发现可疑支出（不知名公司 + 论文服务费 + 单笔 >5000 元 + 投稿前后 3 个月）→ 要求 PI 口头解释。无法解释 → 红灯。

**为什么可行：** 让 PI 自己点下载不触发财务隔离墙；签字承诺书把法律责任压实给签字人；真正买论文的人不敢签——签了就是书面伪证，不签就是自曝。

### 3.9 论文分类与差异化审查

| 类型 | 定义 | 差异化审查 |
|---|---|---|
| A 类 · 原始实验论文 | 含课题组自行产生的湿实验数据 | 完整 9 项 + 物理穿透适用 |
| B 类 · 公共数据挖掘 | TCGA/GEO 等公共数据库分析 | 免样本溯源 + 物理穿透。强化代码复现 + Overclaim。须声明 accession number + 下载日期 |
| C 类 · 综述/Meta 分析 | 文献综述或已发表数据合并分析 | 免图像自查 + 代码复现 + 样本溯源 + 物理穿透。强化 Motivation + Overclaim + AI 文本。检索策略须可复现 |
| D 类 · 方法学/工具 | 新算法、新软件、新实验方法 | 按是否有实验验证归入 A 或 B |

### 3.10 论文被拒后重新投稿

| 变更程度 | 流程 |
|---|---|
| 仅修改格式/期刊，数据结论未变 | 提交新投稿确认信 → 秘书更新归档 → 无需重审 |
| 修改个别图表、补充少量实验（< 20% 面板变更） | PI 提交变更说明 + 新增数据自查 → 秘书 + 生信负责人审新增部分 → 原委员书面确认 |
| 大幅修改、新增关键实验、核心结论变化 | 视为新论文，重走 Phase 2 + 3 全流程 |

冷冻包版本链式关联，每次投稿后变更材料追加原包，生成新哈希值。

### 3.11 举报人保护

内部举报人是学院最早的风控信号。如果内部人不敢说话，造假潜伏多年后由外部耿同学们引爆——损失远超一篇论文。

**三通道举报：** PI 直接沟通 → 党委书记实名受理（PI 涉假时）→ 校级匿名举报（院级利益冲突时）。

**保护：** 举报人不得受打击报复。被报复 → 党委书记介入，暂停 PI 招生资格。举报人需要推荐信 → 学院名义出具替代 PI 个人推荐信。举报人毕业不受调查周期影响，可更换导师或组建独立答辩委员会。

### 3.12 多作者论文责任分配

**不搞连坐。** 责任精确到造假执行者和负有审查义务的通讯作者。

- 通讯作者（PI）：对全文数据真实性负总责，无论造假发生在哪部分
- 第一作者：仅对自己名下造假数据负责
- 参与作者：证明仅提供试剂/方法/样本而未参与造假 → 免予追责
- 无责作者的学位、职称不受该论文影响

**"拼接式归档"：** 多课题组合作论文，各 PI 分别签署本组数据预审单，冷冻包内按课题组分别打包。事后追溯时定位到造假数据所属子包 → 不牵连其他子包负责人。

## Phase 4 · 舆情应急响应

### 4.1 舆情触发与 24 小时内网静默

**触发：** PubPeer 多条负面质疑、知乎/微博/抖音点名本院学者，且引发关注。

**动作：**
- 党委书记下封口令：严禁涉事 PI、学生在网络平台私自回应（配合调查陈述不在此限），时效不超过 72 小时
- 涉事 PI 丧失对外解释权，学院指定一名发言人（党委书记或分管行政副院长）

### 4.2 调取冷冻档案（黄金 4 小时）

**核心原则：不要先问人，先问系统。** PI 会避重就轻甚至撒谎。

- 院长 + 党委书记双人同时在场解封冷冻 Zip（双钥匙机制，单人无法调取或删除）
- 按举报者指出的疑点，去冷冻包里找对应的原始 TIFF/CZI 哈希文件和代码
- 生信负责人验证哈希值是否与归档时一致
- 4 小时内形成内部初步结论：误伤 / 技术盲区 / PI 绕过系统 / 档案缺失

### 4.3 分级回应策略

| 情景 | 底牌 | 回应策略 |
|---|---|---|
| A · 恶意举报/误伤 | 数据没问题、哈希一致 | 强硬反击：公布原始仪器文件 + SHA-256，供学术界公开验证 |
| B · 当年技术盲区 | 档案有异常但未检出 | 坦承局限：当年工具没检出来，已暂停涉事学者 + 升级检测工具 |
| C · PI 绕过系统 | 涉事者违规绕过审查 | 迅速切割：点名具体违反哪条铁律，用制度反证管控有效 |
| D · 档案缺失 | 论文从未通过审查 | 承认漏洞：启动调查为何绕过 + 课题组近三年全部论文追溯审查 |

### 4.4 善后与制度补丁

- 涉事课题组近三年全部论文重新走全流程审查
- 一个月内发布 Workflow v2.0：复盘漏洞 → 升级工具/加固流程/加强合规效力
- 院长在教师大会上做全流程复盘："出了事学院担得起，因为有档案。绕过的代价比造假的代价还大。"

### 4.5 期刊静默撤稿调查

期刊要求配合调查但没有舆情压力时——**应对策略与舆情爆炸完全一致：调档案、拿证据、不私下交易。**

1. 收到期刊调查通知 → 秘书即刻通知院长 + 党委书记，不经过涉事 PI
2. 双人解封 → 调取冷冻档案
3. 7 个工作日内向期刊回复：档案无异常 → 附原始数据支持；发现异常 → 主动撤稿；档案缺失 → 如实告知 + 内部启动调查
4. **底线：宁在期刊面前丢一篇论文，不在公众面前丢整个学院的名声。**

## 验证场景

**场景 A · 数据篡改（同济《Nature》论文）：**
Phase 1 无 ELN/哈希记录 → Phase 1 即暴露 → Phase 2 用 Forensically/ImageTwin 扫描 → WB 拼接被标记红灯 → Phase 3 无法通过终审。

**场景 B · 论文工厂：**
全绿灯通过机器检测 → 随机 10% 触发物理穿透 → 冻存管不存在 → 财务记录显示向可疑公司支付"数据分析服务费" → ⚫ 上报校级 + 公安。

**场景 C · PI 本人造假（同济院长案例）：**
通讯作者为院长 → 回避生效 → 红灯触发 → 党委书记主持调查 → 直接上报校级，不经过学院自行裁定。

**场景 D · 内部举报：**
学生向党委书记实名举报 PI 删数据 → 党委书记单独核查 ELN/NAS → 确认不一致 → 启动 PI 调查流程。

**场景 E · PI 胁迫学生造假：**
PI 口头指令学生替换 WB 条带 → 学生 7 日内向党委书记补报 → 学生免予追责 → 党委书记秘密调查 PI → 学生申请更换导师。

**场景 F · 多作者连坐防止：**
拼接式归档定位到子包-课题组 A → 追责 PI + 第一作者 A → 其他共同第一作者不受影响。

**场景 G · 预印本绕过：**
未审查即上传 bioRxiv → 通知 PI 30 天内补走 Phase 2 → 逾期冻结 3 个月 → 事后发现造假，学院出示"发现问题后立即启动补审"时间线。

**场景 H · 期刊静默调查：**
期刊邮件 → 不转发涉事 PI → 双人解封 → 档案数据一致 → 7 日内提交原始数据支持论文 → 档案不一致 → 主动申请撤稿。
